# Open Gaps

Record only observed unresolved failures or contradictions, with evidence pointer, owning phase, and next repair. Planned but unattempted work belongs in the checkpoint's next action, not here. A phase cannot pass with a gap it owns. Do not delete a gap merely to make a gate pass; close it only after replacement evidence exists, then remove it from this open-only list. Failed attempts and resolutions remain in runtime/phase evidence.
